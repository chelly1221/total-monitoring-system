# UPS · 온습도 장비 설정 디자인 시안

`index.html`을 브라우저에서 열어 장비, 수정/추가, A/B를 선택합니다. 총 8개 화면입니다. Pretendard는 저장소의 `public/fonts/PretendardVariable.woff2`를 사용하며 외부 연결은 필요하지 않습니다.

- **A · 한눈에 설정:** 현재 서버 설정 화면의 3열 구조를 계승합니다. 기본 정보·통신, 알람 기준, 수신 데이터가 나란히 배치됩니다. UPS 음성·파서 세부 설정은 펼쳐서 확인합니다.
- **B · 집중해서 설정:** 수정 화면은 상단 탭과 고정 미리보기 영역으로 구성합니다. 새 장비는 연결 설정 → 알람 기준 → 등록 확인 순서로 진행합니다.

검정 배경, 무채색 입력창과 구분선, 21px 섹션 제목, 15–16px 입력·레이블을 사용합니다. 상태색은 의미가 있는 상태 표시에만 사용합니다. 전역 사이드바는 표시하지 않습니다. 장비 설정은 기존 동작처럼 저장/등록 버튼으로 적용하는 디자인입니다.

이 페이지는 디자인 비교용입니다. 데이터, 알람 이력, 탐지 결과는 표시된 예시이며 실제 서버 설정 변경·장비 탐지·소리 재생을 수행하지 않습니다.

2026-09-22에 A안을 확정해 UPS·온습도·장비상태형의 실제 추가 및 수정 화면 6곳에 적용했습니다. 공통 화면은 `src/components/forms/device-editor.tsx`와 같은 이름의 CSS에서 관리합니다. 장비별 파서·음성·패턴·자동 탐지 기능은 유지하며, 좁은 창에서는 2열·1열로 전환합니다. UPS·온습도 독립 창은 사이드바를 숨기고, 메인 대시보드의 장비상태형은 기존 탐색 구조를 유지합니다.

자동 탐지 목록은 장비명·등록 여부·상세·선택을 한 줄로 표시합니다. 상세에서 IP·MAC·상태·등록 시설·전송 대상과 PC 확인 기능을 제공합니다. 미등록 항목을 먼저 표시하며, UPS는 카드별로 등록 여부를 판단해 각각 선택합니다.
