설정

서버에서 이 PC를 선택하면 UPS별 서버 연결 정보가 자동으로 저장됩니다.

자동 연결 방법

통합알람감시체계 → UPS 추가 → 자동 탐지 (PC)에서
‘2026 1레이더 UPS’를 선택하고 UPS#1 또는 UPS#2를 고른 뒤 저장하세요.

닫기 버튼은 감시를 유지하며 트레이로 숨깁니다.
완전히 종료하려면 트레이 메뉴의 ‘종료’를 누르세요.

설정 백업

UPS 주소·서버 연결·임계값·환경 설정을 JSON 파일로 저장하고 불러옵니다. 기존 UPS 감시 프로그램의 settings.json / ups2_settings.json도 가져올 수 있습니다.
